# 媒体库案例与提炼边界

以下经验于 2026-10-25 从本地资料提炼。路径相对原媒体库根目录；本 Skill 可脱离该目录使用，案例不是运行依赖。复用时定位当前目录并核对，旧验收值不代表新片实测。

## 张骞：历史反差受时序约束

资料：`zhangqian-film/README.md`、`输出/张骞十三年/史料核查.md`、`输出/张骞十三年/audio-work/README.md`、`输出/张骞十三年/验收说明.md`、`zhangqian-film/scripts/verify-film.py`。

提炼：厘清首次出使、后来行动、不同授赏及人数统计对象，字幕与路线/图解同时受证据约束。无配音竖版重新安排字幕，不能直接沿用横版参考字号。

本片 1080×1440、30 FPS、144 秒是案例规格，验收脚本绑定本片参数，只借鉴检查项。

## 郑和：音乐段落与空间解释

资料：`zhenghe-film/README.md`、`输出/郑和下西洋/史料核查.md`、`输出/郑和下西洋/音频制作/README.md`、`输出/郑和下西洋/视觉验收.md`、`输出/郑和下西洋/卡点验收.json`、`zhenghe-film/src/rhythm.json`。

提炼：按实际处理音频的瞬态与起伏排不等长镜头，共享时间数据驱动切镜与局部强调。人物亲历、船队范围、史料记载、现代距离估算分别表述和绘制。未听辨时不把瞬态称为听感确认的强拍。

读代码纠正文档措辞：AI 插画整图 scale/translate 不是真正分层视差，船体摆动/渐显不代表帆面展开。可核实的局部动作包括 `src/art/OceanMap.tsx` 航线/光点/港口脉冲与 `src/scenes/Records.tsx` 独立卡片翻转。新片按真实变化验收，不继承宣传性描述。

## 一句话反复想：场景音效走向内部动作配声

资料：`rumination-film/README.md`、`输出/一句话反复想/研究依据.md`、`输出/一句话反复想/参考分析/参考视频分析.md`、`输出/一句话反复想/验收/字幕阅读速度.json`、`输出/一句话反复想/音效增强版V2/V2优化说明.md`、`rumination-film/public/audio/v2/sound-plan.json`、`rumination-film/scripts/verify_audio_v2.py`、`输出/一句话反复想/音效增强版V2/验收记录.json`。

提炼：研究结果、应用转写和视觉比喻分开。历史片图解语法可迁移，历史事实不能变成心理学证据。

后续用户要求尽量覆盖内部动效的声音。V2 记录 124 个声音事件和 125 个提示点，允许共享瞬态与音乐包络。可复用的是逐动作审计、可见/落位时刻配声、音乐让位与透明覆盖关系，数量不是配额。

两处实际检查经验：CSS 可覆盖组件默认字号；生成字幕页可跨过 Caption 名义空档。旧字速报告和默认样式不能代替实际页验证。

排程误差来自源 PCM 锚点与起始帧，不等于 AAC 逐事件听辨；旧脚本保存了场景源码哈希但未自动核验它，改场景后须重审。

仅改声音时保留原片，用生产 Remotion 声音轨导出混音、复制原视频流封装新版，并核验旧文件、视频流、WAV 与 AAC；画面/字幕/时长改变时不套用此快捷路径。
