# 验收、交付与旧片优化

## 分层验证，结论对应证据

| 层级 | 确认内容 | 证据 |
|---|---|---|
| 内容 | 有依据，字幕和视觉没越界 | 说法表、出处、限定语 |
| 字幕 | 无意外重叠/缺口，完整可读 | JSON/SRT、实际页检查、原尺寸帧 |
| 工程 | 能运行，素材齐，声音用生产定义 | 工程检查、素材清单、命令 |
| 动效 | 解释性变化与声音对应 | 连续帧、事件表、同步误差 |
| 成片 | 参数、解码、编码画面/音轨正常 | ffprobe、解码、成片抽帧、测量 |
| 观感 | 连续节奏、声音层次和字幕易读 | 实际播放范围与检查记录 |

抽帧覆盖每幕、转场前后、拥挤字幕、首尾和复杂图解，同时看原尺寸。动态段用连续帧或短片检查，单帧不能证明动作与节奏。字幕空档按分镜判断，不要求文字铺满每帧。

## 最终 MP4 回读

核对制作简表的预期值，不沿用旧脚本固定帧数/字幕数。以下路径为命令示例，执行时替换成真实文件：

```bash
ffprobe -v error -show_format -show_streams -of json '/实际路径/成片.mp4'
ffmpeg -v error -i '/实际路径/成片.mp4' -f null -
ffmpeg -hide_banner -i '/实际路径/成片.mp4' -vn -af 'loudnorm=I=-18:TP=-1:LRA=11:print_format=json' -f null -
```

第三条用于测量，目标参数按项目调整；读取输入测量，不能把命令里的目标值当成实测值。

检查实际像素与方向、平均/标称帧率、帧数/视频时长、编码和像素格式；普通交付可用 H.264/yuv420p 与 AAC，采样率按约定。完整解码确认无解码错误，结合帧数与时长检查截断；通过成片抽帧或播放检查黑屏、丢素材和缺字。

从最终 MP4 再抽片头、正文复杂段、转场与片尾。直接解码其音轨，测综合响度、真峰值、非有限/削波样本、首尾及音画时长差，不能用中间 WAV 代替。核对关键声音的时间映射，能播放时听辨是否被音乐盖住。

AAC 可能有延迟或尾部补齐。报告容器/视频/音频时长与差值，检查额外部分是否静音合理；不能只因长几十毫秒断言掉帧，也不能无条件放过截断。

无法播放时说明已做的参数、解码、抽帧和测量，不声称看完、听过。导出失败则保留工程与诊断，明确尚无合格 MP4。

## 旧片修改保持边界

先明确本次改内容、画面、声音还是发布物料，检查工程与已交付文件，保护原版。

仅改声音且画面/字幕/时长不变时，可从生产声音定义渲染新轨，复制原视频流封装新版；同步更新工程使其可完整重渲。核对原文件未变、视频流哈希、WAV 与 AAC，仍做新版完整解码与音轨验收。

不要把声音增强称为新增视觉动效，画面时长改变后不能直接套复制视频流。旧片 `verify-film.py` 通常写死参数，只借鉴检查项，不能原样证明新片通过。

## 最小交付

按本次阶段交付。完整成片一般包含：可编辑工程与锁文件、运行/导出命令、实际 MP4、配套封面、发布文案、结构化字幕与 SRT、研究依据、关键素材来源、验收范围和结果。需要版本比较时记录文件/视频流哈希。

沿用项目目录，不强行重构。记录浏览器与字体等本机依赖，新增字后更新字体子集，不默认有权分发系统字体；渲染所需素材可本地化时本地化，区分本机可重渲与跨机可复现。

## 封面与发布文案默认随片交付

- 每次完成视频时默认同时导出封面，除非用户明确不要；仅做研究、脚本或样片时不自动扩大交付阶段。封面聚焦一个问题、一个主意象与少量文字，必须沿用系列已确定的背景明度、配色、字体、图形材质与标题逻辑，在手机缩略图检查辨识度。
- 本用户主封面默认竖版 3:4，实际像素1080×1440；影片即使是16:9，封面也按3:4独立构图。只有明确要求时才改比例或补充横版，不能用横版代替默认主封面。补充版本也要保持同一视觉身份。优先复用正片可编辑图形与设计变量，避免每次重新随机生成一套风格。
- 封面画幅可不同于影片；横改竖需重新构图，不能只裁边或套框。实测像素、比例、方向、中文、安全区与格式。
- 发布文案默认与成片、封面一起交付，保存为同一交付目录的 `发布文案.md`，默认给一个主标题、2–3句可直接发布的简短正文、一句简短自然互动和3–5个贴题话题标签。正文不复述整片论证，详细研究出处保留在独立依据文件中；需要表达的事实限定仍须保留。未指定平台时先给通用短稿；平台明确时适配其语气与篇幅。用户明确不要文案或仅做研究、脚本、样片时，按其阶段交付。
- 文案与最新版正片使用相同事实边界，不添加惊人数字、疗效保证或未经支持的断言，不捏造作者亲历。标题、封面文字、正文与最终成片要互相一致；视频改版后同步检查文案。物料完成不等于已发布。

## 系列一致性与收尾验收

交付前并排查看全片联系表与封面：背景明度、字体、强调色、线条和材质应属于同一系统。对“更多动效”的验收，记录真实新增的局部动作，而非只统计粒子或转场数量。

片尾至少单独检查最后一幕开始、回扣动作完成、稳定停留、淡出中段与最终帧；声音检查结束乐句/包络、尾部电平和音画时长。标题提出的问题已有回答、最后字幕读完、动作完成且声画共同收束，才算结束自然。
