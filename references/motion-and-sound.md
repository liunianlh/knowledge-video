# 参考转化、图解动效与动作声音

## 看参考的工作方式

对指定的每个视频读取时长、尺寸、帧率与音轨；代表帧覆盖全片，再在路径推进、图符到达、文字落位和转场附近密集采样。看原尺寸关键帧和带时间的联系表，必要时播放片段。

记录字幕/关键词/来源/图解层级、底图如何复用、具体动作的起始/落位/余韵，以及配色和运动如何随情绪改变。把视觉观察、音频测量、实际听辨分别记录。

场景检测仅反映画面差异，未命中不代表无局部运动；响度相近不证明用了某类音效。借鉴形式与借鉴事实分开。

## 动作应解释这句话

| 关系 | 可采用的动作 | 避免的误导 |
|---|---|---|
| 迁移、传递、探索 | 路径绘制、节点到达、跨尺度镜头 | 示意路线变成确定行程 |
| 数量、时间、规模 | 共享基线比较、时间轴、数字分解 | 比例扭曲或虚构精度 |
| 机制、反馈 | 闭环运行、变量变化、回流与出口 | 暗示未经证实的生理因果 |
| 不同条件、原话与解释 | 同对象分层、两栏分流、卡片拆开 | 教学例子伪装实验数据 |
| 实践步骤 | 对象归位、路径接通、动作完成 | 表现成保证生效 |

每幕确定一个主视觉动作，粒子、光带、景深服务层次；主字幕阅读期稳定。华丽来自层次、材质、连续性与节奏，不依赖持续频闪。

背景、对象、路径、标签和字幕独立。整图缩放、摆动不等于主体局部动画，也不等于前中后景视差；用同镜头多个时刻验证具体对象确实变化。人物和物件生成素材维护身份/画风一致，精确图表与文字由工程控制。

## 统一视觉、增加局部动作与片尾回扣

- 制作前确定背景明度、字体、标题层级、强调色、图符线宽、材质和封面构图。相邻幕的变化应属于同一系统；不得用无关的白底/黑底模板交替代替章节变化。
- 本用户当前系列基线：深蓝黑背景、米白主文字、珊瑚色表示紧张、薄荷色表示缓和、细线图形与轻颗粒。除非用户明确改版，后续正片及封面延续这一身份；主题可以换意象，不随意换字体、明度和画风。
- 更多动效先补解释链：出现、展开、传递、反馈、改变、归位。流向光点应沿实际关系路径移动；分离、汇聚、拉伸和松开应发生在相应对象上。连续运动不能遮挡字幕或伪造研究数据。
- 可以为一句字幕安排多次图内动作，但不能靠加速字幕凑镜头。持续环境运动和重复流动可共享声底；新出现的关键变化应重新审视声音提示点。
- 收尾回扣开场的疑问与主意象，并显示变化后的表达或关系。先完成最后一个动作，再留出稳定阅读与余韵；可从约3–5秒停留和约1.5–3秒画面淡出起步，按音乐和内容调整，不机械套固定时长。音乐淡出可更早开始，避免硬截乐句。
- 修改片尾时同步更新总帧数、字幕结束、声音排程和淡出；旧片最后几秒的声音/画面结论不能沿用。

## 音乐与动作是两种锚点

分析最终会放进工程的音频；裁剪、循环或变速后核对时间映射，不沿用旧片时间或 BPM。

- 音乐结构：候选 BPM、拍点、实际瞬态、能量起伏、停顿与段落，用来安排章节、转折、高潮和落幕。
- 动作结构：文字清楚可见、物件撞击/分离、路径到达、数字落位等时刻，内部声音优先跟随它们。
- 自动检测是候选，平均 BPM 不能代替乐句。仅有瞬态数据时称“与测得瞬态对齐”，不声称已听辨每个强拍。
- 检查音乐、字幕与镜头时长；可延长停留、压缩知识点或重排，不牺牲阅读套固定八拍。

保存共享节奏数据与动作声音表，格式沿用工程。视觉同步点按实际可见动作确定，不直接取缓动末帧；父层透明时已经执行的动画也不能提前配出明显声音。

## 关键动作尽量有可感知的声音

不能只给切镜配 whoosh。先列内部关键动作，再选落字、回放、描线、节点、分离、拉远等声音。

覆盖类型：独立声音；同刻关联动作的共享瞬态；连续声或音乐包络；有理由的静默。共享要记录覆盖关系，静默不能计作已加声。

“关键动作都有处理”优于“声音数量很多”。装饰粒子无需逐个响，避免所有事件同音色、同响度。分主动作、次动作、过场和环境层，保留疏密。拟音对应可见动作，例如杯子入场不应冒充吞咽。

## 文件开始不一定是听觉重音

对实际音效测量有效起音和能量峰值。描线/扫动常参考起音，落字/撞击常参考峰值，按声音形状决定。

```text
visualTargetFrame = sceneStartFrame + localSyncFrame
soundStartFrame = visualTargetFrame - measuredAnchorFrame
actualAnchorTime = soundStartFrame / fps + measuredAnchorSeconds
alignmentErrorMs = (actualAnchorTime - visualTargetFrame / fps) × 1000
```

映射最近视频帧时，单纯取整误差最多约半帧：`1000 / (2 × fps)` 毫秒。这仅是源音效参考位置加排程的量化误差，不是从最终 AAC 独立识别事件得出的同步误差，更不是播放链路的感知保证。

负起点需延后视觉同步点、换声音或裁剪并重测；不能截到第 0 帧后仍报告零误差。头部静音、淡入与变速均影响锚点。场景、缓动、顺序、时长或素材改变后重审提示点；保存了源码哈希不等于检查了哈希，旧 `passed` 不能沿用。

## 混音与可编辑性

- 音乐、音效、配音（如有）独立，保留原音乐。原创合成音可降低依赖，外部素材记录来源与使用条件。
- 重点动作可短暂降低音乐并平滑恢复，不能让全曲失去存在感；增益按本次素材和听感设置，不复制旧片数字。
- 检查重叠叠加、低频堆积、高频刺耳和首尾包络，避免只靠限幅器隐藏过载。
- 未指定标准时，可用约 -18 LUFS 综合响度、真峰值不高于 -1 dBTP 作为本系列可调起点，不称平台要求或合规结论。以实际目标、编码音轨和试听判断。
- 事件表与生产声音定义一致；离线混音与预览不能各用一套漂移的时间表。
- “有声音节点”“覆盖表通过”“编码后听得清”是不同层级，测量不能替代听辨。
