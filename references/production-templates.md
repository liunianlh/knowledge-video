# 按需采用的制作模板

已有工程可表达相同信息时直接沿用，不机械新增所有文件。下面的动作是虚构教学示例，不是题材事实。

## 制作简表

```text
核心问题：本片要回答的一个问题
受众与结论：看完应理解的一句话
本次阶段：研究 / 脚本 / 预览 / 成片 / 局部优化
画布与时间：width × height、FPS、时长范围
叙事声音：中文字幕、是否配音、音乐真实路径
参考：哪些借鉴形式，哪些支撑事实
交付与假设：本次文件、待核实事实及未确定规格
```

## 分镜表

| 场景 | 帧范围 | 主字幕 | 证据/边界 | 图解动作 | 音乐节点 | 内部声音 |
|---|---|---|---|---|---|---|
| Split | [240, 480) | 原话与推测，是两件事。 | 情境示例 | 卡片拆成两层，第 300 帧落位 | 第 240 帧章节转折 | 第 300 帧分离音 |

范围采用前闭后开 `[start, end)`，时长为 `end - start`。工程采用其他约定时保持一致并明确转换。

## 动作声音最小例子

```json
{
  "fps": 30,
  "scene": "Split",
  "sceneStartFrame": 240,
  "cues": [
    {
      "id": "card-separate",
      "action": "卡片分离落位",
      "localSyncFrame": 60,
      "targetFrame": 300,
      "coverage": "sound",
      "eventId": "split-sfx"
    }
  ],
  "soundEvents": [
    {
      "id": "split-sfx",
      "file": "audio/split.wav",
      "reference": "peak",
      "measuredAnchorFrame": 3,
      "measuredAnchorSeconds": 0.1,
      "startFrame": 297,
      "gain": 0.6,
      "covers": ["card-separate"]
    }
  ]
}
```

数值只展示字段关系，真实锚点来自测量，增益来自混音。按需补时长、优先级、音乐让位、素材身份与共享/静默理由，不为简单片子预设配置系统。

## 验收记录

记录真实路径、大小；视频宽高/FPS/帧数/时长/编码；音轨规格/时长/响度/真峰值；时间差和编码补齐；字幕实际页与内容证据；动作提示点及覆盖类型；全文件解码、编码后抽帧、音轨检查和播放范围。将通过、未通过、未检查项分开，不合成虚假的全通过。
